# Morrow privacy policy

Public information for Morrow, the Android routine, record and reflection app distributed through Google Play as `com.hourveil.app`.

- `index.html` contains the Korean, English and Japanese privacy policy. It is a static page with no analytics, cookies, scripts, account system or external font request.
- `favicon.svg` is Morrow's vector identity, exported from the same source as the app icon.
- `.nojekyll` keeps the page as a plain static GitHub Pages site.
- Support: cluenode@gmail.com

This repository contains public policy and branding files only. It does not contain the application source code, signing keys, user records or purchase evidence.

Publish from the root of `main` using GitHub Pages. This is document hosting, separate from Morrow's on-device data storage. No app synchronization service is created.
